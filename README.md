# ECG CDSS — Deep Learning Clinical Decision Support System

## Overview

This project builds a **Clinical Decision Support System (CDSS)** for automatic diagnosis of 12-lead electrocardiograms (ECG) using deep learning, with integrated explainability through **1D Class Activation Mapping (1D CAM)**.

The system is based on the ResNet-1D architecture published by Ribeiro et al. (2020), which achieves cardiologist-level performance on six rhythm and conduction abnormalities. This project extends that work by:

- Exporting the model to a **dual-output ONNX graph** that simultaneously exposes diagnostic probabilities and intermediate convolutional feature maps.
- Computing **1D CAM attention vectors** directly from the dense weight matrix, adapted to the network's `Flatten` layer (not Global Average Pooling).
- Rendering calibrated **thermal heatmaps** overlaid on a medical-grade ECG Canvas (25 mm/s, 10 mm/mV).

---

## Reference Model

This system is built on top of the model introduced in:

> Ribeiro, A. H., Ribeiro, M. H., Paixão, G. M. M., Oliveira, D. M., Gomes, P. R., Canazart, J. A., Ferreira, M. P. S., Andersson, C. R., Macfarlane, P. W., Meira Jr., W., Schön, T. B., & Ribeiro, A. L. P. (2020). **Automatic diagnosis of the 12-lead ECG using a deep neural network.** *Nature Communications*, 11, 1760. https://doi.org/10.1038/s41467-020-15432-4

The original model weights and dataset (`model.hdf5`, `ecg_tracings.hdf5`) are distributed by the authors under their own terms and are **not included in this repository**.

## Diagnostic Classes

The model outputs independent sigmoid probabilities for six conditions:

| Code    | Condition                     |
|---------|-------------------------------|
| `1dAVb` | First-degree AV block         |
| `RBBB`  | Right bundle branch block     |
| `LBBB`  | Left bundle branch block      |
| `SB`    | Sinus bradycardia             |
| `AF`    | Atrial fibrillation           |
| `ST`    | Sinus tachycardia             |

## Architecture

```
ml/scripts/export_dual_onnx.py
        |
        v
[ Keras ResNet-1D ]  -->  [ Dual ONNX Graph ]  -->  backend/models/ribeiro_dual.onnx
        |                         |
        |                         +-- Output 0: probabilities  (1, 6)
        |                         +-- Output 1: feature_maps   (1, 16, 320)
        |
        +-- Dense weights  -->  backend/models/dense_weights.npy  (5120, 6)

backend/models/
        |
        v
[ ONNX Runtime Inference ]  -->  probabilities + feature_maps
        |
        v
[ 1D CAM Computation ]
   W_c = dense_weights[:, class]          # (5120,)
   W_c_2d = W_c.reshape(16, 320)
   cam_raw[t] = sum(A[t,:] * W_c_2d[t,:])
   cam = relu(cam_raw) -> interpolate(16 -> 4096)
        |
        v
[ HTML5 Canvas Renderer ]  -->  ECG signal + thermal CAM overlay
```

## Getting Started

### Prerequisites

- Python 3.10+
- Original model weights from the Ribeiro et al. repository placed at `ml/raw/model.hdf5`
- Original dataset placed at `ml/data/ecg_tracings.hdf5`

### Setup

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Run the ML pipeline

```powershell
# 1. Export the Keras model to a dual-output ONNX graph + save dense weights
python ml/scripts/export_dual_onnx.py

# 2. Validate ONNX inference and end-to-end CAM computation
python ml/spikes/test_inference_cam.py

# 3. Generate a patient JSON fixture for frontend testing
python ml/scripts/export_sample_json.py

# 4. Launch the ECG Canvas spike viewer
python -m http.server 8000
# Open: http://localhost:8000/frontend/spikes/test_canvas.html
```

## Technical Notes

- **Production constraint:** `backend/` code uses only `onnxruntime` and `numpy`. TensorFlow and Keras are strictly limited to `ml/scripts/export_dual_onnx.py`.
- **CAM architecture:** The Ribeiro ResNet-1D uses a `Flatten` layer (not Global Average Pooling). The dense weight matrix is `(5120, 6)` and is reshaped to `(16, 320)` for 1D CAM computation. Do not change this to standard GAP-based CAM.
- **ECG Canvas calibration:** 1 mm = 4 px, sweep speed 25 mm/s, voltage gain 10 mm/mV.
